## 部署与安全

- 后端、管理前端、飞书 WebSocket Worker 均运行 `8cd452a`。
- PostgreSQL 已在收尾前完成备份，备份文件权限为 `600`。
- 数据库密码已轮换，后端和 Worker 使用新凭据完成健康验证。
- 飞书 Worker 使用 Docker 内部地址 `http://backend:8000/api/v1/channels/feishu/events`。
- 管理前端通过服务器 `8083` 对 PC 与移动端提供统一入口并继续要求管理员令牌；后端仅在 Docker 内网和服务器回环地址提供服务。
- Docker 已设置开机启动，核心容器使用 `unless-stopped`；systemd 每分钟执行一次健康守护，异常时自动恢复前端或后端。
- 旧版镜像和停止的回滚容器暂时保留，便于试运行初期快速恢复。
